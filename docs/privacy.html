Privacy Policy

Pixel Helper inspects tracking requests in Safari on websites you allow. The observed data stays in your browser; the extension does not send it to a Pixel Helper server.

Last updated: September 25, 2026 · Publisher: Maciej Szamowski

What the extension can see

On websites for which you grant Safari access, Pixel Helper observes resource request URLs associated with Google tag, Meta Pixel, TikTok Pixel, Reddit Pixel, and X Pixel. It may show the website domain, provider, Tag ID or Pixel ID, event name, request endpoint, time, and URL parameter names and values. A website can put personal information in a request URL, so those values may contain personal information.

Pixel Helper does not inspect POST request bodies, page text, or cookies. An observed request does not prove that a provider received it.

Where the data goes

The extension keeps up to 100 observed events in memory for the current page and shows them in its popup. Those events are cleared when the page's extension script ends, such as when you navigate away, reload, or close the tab. The popup saves only your light or dark theme preference locally in the browser until you clear extension data.

Pixel Helper does not create an account, add analytics, or transmit observed browsing data to the publisher. Requests made by a website to tracking providers are controlled by that website and your browser settings, not by Pixel Helper.

This website and support

This site adds no analytics or advertising scripts. It is hosted on GitHub Pages. GitHub says it logs visitors' IP addresses for security; its own privacy statement explains its handling of site visits.

Support is handled through GitHub Issues. Issues are public. Do not include private URLs, request parameters, or other sensitive information in an issue.

Questions

For a question about this policy or the extension, open a GitHub issue without including sensitive information.
