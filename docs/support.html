Set up Pixel Helper

  1. Open Safari → Settings → Extensions and turn on Pixel Helper.
  2. Grant Pixel Helper access to the websites you want to inspect.
  3. Reload the page, open Pixel Helper in the Safari toolbar, and select a provider icon to inspect its tags and events.

If nothing appears

Check that Pixel Helper has permission for the current website and reload it. The site must make a request to a supported provider while the page is open. Content blockers and browser privacy settings may prevent requests from being made or observed.

Pixel Helper currently recognizes Google tag, Meta Pixel, TikTok Pixel, Reddit Pixel, and X Pixel. It sees request URLs, so details sent only in POST bodies may be missing.

Contact support

Use GitHub Issues to report a problem or request a feature. Include your macOS and Safari versions, what you expected, and what happened. Issues are public: remove private URLs and request values from screenshots before posting.
