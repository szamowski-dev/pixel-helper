Using Pixel Helper

Terms of Use

Pixel Helper is a diagnostic tool for inspecting tracking requests observed by Safari.

Understanding results

Pixel Helper reports requests that Safari makes visible to the extension. Results can be incomplete because of website access permissions, browser protections, network conditions, or request data placed in a POST body. A detected request does not confirm delivery to a provider. Pixel Helper does not inspect server-side conversion events.

Use the results as a debugging aid and verify important conclusions with the provider's own tools or your server logs.
